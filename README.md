
# 🎬 FlickPick

**Swipe to find your next movie.**

FlickPick is a movie discovery app that helps you decide what to watch by swiping through movies.

## Features

* 🎬 Browse movies
* 👉 Swipe right to add a movie to your Watch List
* 👈 Swipe left to skip a movie
* ❤️ Like / ❌ Dislike buttons
* 📋 Manage your Watch List
* 🗒️ Show Categories and each movies list
* 🔍 View movie details
* 👤 User login and logout
* ✨ Animated movie cards and selected movies

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Motion
* TMDB API

## How It Works

1. Log in to your account.
2. Browse the recommended movies.
3. Swipe right or click ❤️ to pick a movie.
4. Swipe left or click ❌ to skip it.
5. After finishing, see the movies you picked.
6. Your selected movies are added to your Watch List.
